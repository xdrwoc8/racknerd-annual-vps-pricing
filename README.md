## 便宜vps年付的三个算术陷阱

**月均价不等于能按月付。** $20/年 除以 12 是 1.67 美元/月，这个数只用来横向比价。结算页扣的是一整年，钱一次性出去，中途不想要了也拿不回来。RackNerd 的常规档确实有月付，单价高于年付摊薄后的价格；想先验证线路，可以拿常规月付档试一个月，确认延迟和丢包能接受，再回头买特价年付。
